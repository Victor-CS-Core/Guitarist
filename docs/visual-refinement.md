# Acoustic visual refinement

Approved by the user after reviewing the visual improvement recommendations.

- Added one original acoustic-guitar focal image.
- Enlarged supporting text, instructions, status labels and chord diagrams, using darker walnut tones.
- Made Start practice the primary dashboard action and removed its repeated lower callout.
- Replaced repeated chord initials with curriculum-derived chord shapes, a reconstruction preview, and string/note previews.
- Kept maple and cream as the base, with denim-blue primary actions, muted copper accents, and coordinated badge colors. No green.
- Checked desktop and 390px mobile layouts and preserved the existing practice/assessment flows.
